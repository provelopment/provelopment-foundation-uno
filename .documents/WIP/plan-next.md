## One unissued candidate

**U03 validated Page document, explicit visibility and publication authorization, routing and
metadata (candidate only, not issued).** A later bounded stage could turn the now-safe, confined source
payload into a validated Page document — heading, body, description — and then require an **explicit
Owner publication decision** before any address becomes a real HTTP route. That stage, and only that
stage, would own: the Page-document schema, the `public | unlisted` decision with its reserved-Home
rule, HTTP status/error behaviour for unmatched and invalid addresses, metadata with canonical
advertising and `hreflang`, and the Owner's choice about any optional base path.

Two boundaries carry forward and may not be inferred from the confined reader now complete: a safely
read source is **not** a published Page, and no manifest field, property `public` flag or JSON
visibility value can authorise publication by itself. That work needs its own Owner-installed work
order, its own exact-path ledger and its own independent tests on both hosts; nothing in this note
authorises it.
