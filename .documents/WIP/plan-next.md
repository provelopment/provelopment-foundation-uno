## One unissued candidate

**Owner domain, explicit publication decision and real HTTP (candidate only, not issued).** A Site may now declare
an optional canonical base that the accepted contract validates, and a pure reader reports either that stored base
or a closed refusal; the committed declaration still states none. What remains is Owner work this Agent cannot
infer: choosing the real public origin, installing it as that declared base, deciding in an explicit order what is
published, and only then enabling a real route with real HTTP status and error behaviour, emitted canonical
advertising and `hreflang`, locale routing for the declared locales, and sitemap and robots policy — each behind
validated contracts, never behind an alias or a request Host.

Two boundaries carry forward: a validated declaration is not a chosen production domain, and a prepared delivery
candidate is not a publication decision.

That work needs its own Owner-installed work order, its own exact-path ledger and its own independent tests on
both hosts; nothing in this note authorises it.
